Help

Push to Talk: Press and hold the "Push to Talk" button to record. Release to stop and transcribe. After a few seconds the transcribed text will be inserted into the text area at the cursor position.

Dictate: Only available in Browser Speech mode. Click the "Dictate" button to start continuous dictation; the button turns into a red "Stop" button while active. Click it again to stop, or let it run for up to 2 minutes (auto-stops to prevent unintended recordings). Text is inserted live into the text area as you speak.

Read: Uses the browser's built-in speech synthesis to read out the text starting from the current cursor position (or from the last position where text was inserted). Click it again (it turns red and reads "Stop Reading") or click it to stop. The selected dictation language is used for the voice when available.

The Fixup button will attempt to correct any transcription errors, correct grammar and spelling and execute any correction instructions in the text and format it, like a dictation assistant.

The Process button lets you run an arbitrary prompt on the text with the AI. It shows a dialog where you can type a prompt (e.g. "Summarize this", "Translate to German") or pick one of your last 20 used prompts from the dropdown. The result replaces the text.

The Render button displays the text as rendered markdown instead of the plain textarea. Click into the rendered text to switch back to editing.

Transcription engine: Use the dropdown to choose between two engines. Whisper (OpenAI) records a snippet and sends it to the OpenAI Whisper API, which keeps typing while you stop and gives the best accuracy (needs an OpenAI API key). Browser Speech uses the browser's built-in speech recognition, which inserts text live as you speak. It needs no API key and works fully locally, but accuracy and supported languages depend on your browser.

If there is already text in the text area this application will provide it to the AI as context (Whisper mode). This improves the quality of the transcription because the AI can guess better which word you meant if there are several words that sound alike, and also because the AI knows the beginning of the sentence if the cursor is in mid-sentence.

In Whisper mode this application is meant for a browser on a desktop computer, and is based on the OpenAI Whisper AI. You will need an OpenAI API key to use this application.
